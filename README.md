# Практическая работа 3 — очистка, анализ и предобработка данных

**Датасет:** [IBM HR Analytics Employee Attrition & Performance](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset) (Kaggle), 1470 сотрудников, 35 столбцов.
**Задача:** бинарная классификация — уволится сотрудник (`Attrition = Yes`) или нет.

**Выполнил:** Гегечкори Георгий

## Блокноты

| Файл | Содержание |
|---|---|
| [`PR3_part1_cleaning_EDA.ipynb`](PR3_part1_cleaning_EDA.ipynb) | Очистка (дубликаты, пропуски, логические ошибки), анализ 25 % данных: графики, среднее и медиана, 4 гипотезы и их проверка на оставшихся 75 % |
| [`PR3_part2_preprocessing.ipynb`](PR3_part2_preprocessing.ipynb) | Разделение train/test 80/20, сравнение методов масштабирования на `MonthlyIncome`, предобработка всех столбцов |

## Как запустить

Открыть блокнот в Google Colab (**Файл → Открыть блокнот → GitHub**, вставить ссылку на репозиторий) или локально в Jupyter.
Данные — файл `WA_Fn-UseC_-HR-Employee-Attrition.csv` в корне репозитория; если файла рядом нет (например, в Colab), блокнот сам скачает его с Kaggle.

## Кратко о результатах

- Дубликатов и пропусков нет. Найдены логические ошибки: 244 невозможных значения `NumCompaniesWorked` (заменены на пропуски) и три столбца ставок, не согласующиеся с доходом (удалены).
- Подтверждены гипотезы: сверхурочная работа (увольняются в ~3 раза чаще), стаж ≤ 2 лет (в ~2,5 раза чаще), более низкий доход уволившихся (в том числе внутри одного уровня должности). Гипотеза о различии по полу не подтвердилась.
- Для `MonthlyIncome` лучший метод — `log1p + StandardScaler`. Итоговая предобработка: `ColumnTransformer`, обученный только на train, 44 признака без пропусков.
